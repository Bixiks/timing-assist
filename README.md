# Timing Assist

Geode mod for Geometry Dash 2.2081 (Windows). Holds a click for a few ms until the timing is safe, then lets it through. See `about.md` for how it works.

## Building
Push this folder to a GitHub repo. The workflow in `.github/workflows/build.yml` builds it on every push. Grab the `.geode` file from the run's **Build Output** artifact and drop it in your `geode/mods` folder.
